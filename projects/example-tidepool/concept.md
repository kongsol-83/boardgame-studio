# 조수 웅덩이

**예제 프로젝트입니다.** 파이프라인을 보여주려고 만든 것이지 실제 설계가 아닙니다.

## 핵심 동사

물이 빠진 시간 안에, 남들보다 먼저 좋은 자리를 훑는다.

## 이 동사가 만드는 순간

- **고민**: 지금 자원을 쓸 것인가, 다음 물때를 노릴 것인가
- **탄성**: 남이 노리던 자리를 한 발 앞서 채갔을 때
- **승리감**: 한 번에 크게 먹은 게 아니라 매 물때를 조금씩 앞섰을 때

## 기본 스펙

| 항목 | 값 |
| --- | --- |
| 인원 | 2-4인 (베스트 3인) |
| 플레이타임 | 30분 |
| 무게 | 2.0 |
| 타깃 | 가족, 보드게임 입문자 |

## 안 하는 것

- 확장, 캠페인, 비대칭 진영
- 플레이어 제거
- 숨겨진 정보 (예제이므로 완전 공개 정보로 둔다)

## 목표 컴포넌트 규모

액션 카드 한 종류 28장, 지형 타일 24장, 자원 토큰 40개, 보드 1장.

컴포넌트 종류를 일부러 섞어뒀습니다. 규격 해석기가 카드, 타일, 작은 토큰, 큰 보드를
각각 어떻게 다루는지 한 프로젝트에서 볼 수 있게 하려는 것입니다.
